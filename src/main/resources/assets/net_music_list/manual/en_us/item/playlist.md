# Playlist

The core item of this mod, used to store and play multiple songs simultaneously.

******

## Interface

Right-click to open an interface where you can perform song-related operations.

```⇌```: Set playback mode (currently available: Shuffle, Single Loop, List Loop)

```↑```: Move the selected song up

```↓```: Move the selected song down

```Delete```: Delete the current song

```Add Song```: This option is at the very bottom of the list. Selecting it activates **Add Song** mode (explained below).

******

Hover the mouse over a song to view its information. Click to select a song. When a song is selected, the item tooltip of the Playlist will change to display that song's information.

Click the ```⚙``` in the top-right corner to open this mod's settings.

******

## Burning

Simply place it into a burner to burn.

However, the Playlist behaves differently depending on whether a song is selected or not. If no song is selected, new songs will be appended. If a song is selected, it will **overwrite directly**.

This mod adds a **list** burning method. Enter ```list/``` followed by the list ID in the input box to burn.

## Playback

Place it in the **Music Player** of the **Net Music** like a normal music disc, or put it in a maid's backpack.
