# Portable Player Entity

The entity form of the Portable Player.

******

## Usage

Right-click to interact:

If the hand is empty and there is no disc in the player, the player will be picked up. Otherwise, the disc will be returned.

If holding a disc, it will be swapped with the disc (or empty air) in the player.

## Passenger

It is recommended to install the [Carry On](https://modrinth.com/mod/carry-on) mod, which allows placing the Portable Player Entity on other entities by picking it up.

The Portable Player Entity will automatically ride seats from the Create mod (including those on trains). This functionality is provided by Create.
