# Music Cache Function

This feature allows downloading music to the local storage during playback. (Only supports Netease Cloud Music)

Once enabled (disabled by default), music will be downloaded when played. The path is:

```Game Directory/config/netMusicListCache```

If **Global Cache** is enabled, the path is:

```C:\Users\Current Username\netMusicListCache```
