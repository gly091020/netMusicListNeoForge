# Integration Content

1. Now the record player can be used as a display source for the Display Link, showing progress bar, song information, playlist, and lyrics.

> To display lyrics, you need to enable "Enable Server-side Lyrics [alpha]" in the configuration file.

2. Now the record player can be used as a target for the Mechanical Arm.

All integration content can be viewed in the gallery.
