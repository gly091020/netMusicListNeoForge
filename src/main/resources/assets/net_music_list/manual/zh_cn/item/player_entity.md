# 随身播放器实体

随身播放器的实体形态。

******

## 使用

右键交互：

如果空手且播放器中没有唱片，则会收回播放器，否则返还唱片。

如果手中有唱片，会与播放器中的唱片（或是空气）交换。

## 乘客

推荐安装 [Carry On](https://www.mcmod.cn/class/1081.html) 模组，可以通过搬起随身播放器实体来实现放置在其他实体上的效果。

随身播放器实体会主动乘坐机械动力的坐垫（包括火车上的），此功能来自机械动力。
